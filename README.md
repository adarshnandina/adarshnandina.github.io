# adarshnandina.github.io

Personal site of Adarsh Kumar Reddy Nandina: <https://adarshnandina.github.io>

Built with Jekyll and GitHub Pages, using the [Jalpc](https://github.com/jarrekk/Jalpc) theme (MIT).

## Local development

```sh
bundle install
bundle exec jekyll serve   # http://127.0.0.1:4000
```

## Where to edit

- `_config.yml`: site title, author info and social links
- `_data/index/*.yml`: projects, links, career and skills sections of the landing page
- `_posts/`: blog posts
